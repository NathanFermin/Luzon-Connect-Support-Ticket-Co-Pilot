
# Router Blinking Red

Last Updated: 09-12-2026
Helpful votes: 56

If your router is blinking red it could mean one of the following:
- Insufficient Power
- Loose Cables
- Internet Outage

Step 1: Ensure all cables attached to your router are firmly secure.
Step 2: Ensure the router is using the provided power adapter. 
Step 3: If the issue persists, check if there is an outage in the customer's area.
